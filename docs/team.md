# 团队与职责

> **当前分工金标准：[1123任务文档](tasks/T-008.md)。** 本页用于快速了解团队角色；若本页、其他文档、网页、Roadmap、PPT 或讲稿与 1123任务文档冲突，执行 1123任务文档。

## 张馨月

**角色：项目负责人；协调与集成负责人。**

- 负责项目日常推进、任务协调和阶段状态维护；
- 负责公共 backbone、`Engine`、整体架构和实验运行流程；
- 汇总各模块提出的公共对象和接口，组织接口对齐；
- 绘制系统运行时序图，组织模块集成、冲突处理和回归验证；
- 审阅其他开发成员提交到集成分支的 Pull Request；
- 不代替领域负责人决定其内部算法或完成全部接口设计。

张馨月不负责网站前端、Dashboard、可视化门户或部署基础设施的搭建与维护。这些展示与运维工作由技术侧统一处理。

## 李文浩

**角色：技术顾问；LLM 与计算方向研究顾问。**

- 对软件架构、LLM 决策、计算实验、复现和关键技术方案提供建议；
- 评审重要架构、公共接口和阶段成果；
- 承担部分实验与关键技术工作；
- 检查技术结论是否与证据相称；
- 在受控提案流程中提交需要张馨月和刘充双人评审的方案。

## 刘充

**角色：经济学研究顾问。**

- 对市场、Lange、Cockshott 和劳动配置机制进行专业把关；
- 评审行为假设、信息条件、福利定义与结果解释；
- 识别制度比较中的概念混淆或不公平条件；
- 在关键节点提供咨询与经济学评审；
- 不承担日常任务分派、代码集成或展示系统维护。

## 杜芃烨

**角色：Decision、LLM 与 Memory 负责人。**

- 负责不同决策场景的通用执行框架；
- 负责 Harness、上下文装配、工具调用和结构化结果处理；
- 负责远程 API、本地模型和规则基线等模型适配；
- 负责决策记忆、历史记录检索和可供上下文使用的决策侧视图；
- 与领域负责人共同确认每类决策需要什么信息、返回什么行动；
- 不结算交易，不自行修改权威世界状态。

## 张津阁

**角色：World 与确定性规则负责人。**

- 负责世界初始化、世界对象和权威物理状态；
- 负责生产、运输、消费、健康、库存等确定性规律；
- 负责行动的权限、容量、资源和时间约束验证；
- 根据已确认的行动和机制结果完成确定性结算；
- 向其他模块提供经过约定的世界信息或观察结果；
- 不负责实验总流程的主动调度。

## 王逸忱

**角色：Market 与 Firm 负责人。**

- 负责粮食、铁等商品市场的订单、订单簿、撮合和出清；
- 负责市场经济中的分散式劳动力市场；
- 负责企业在经济上需要进行的生产、雇佣、投入购买、产品出售和报价决策定义；
- 提供价格、成交、未成交需求和 Lange 所需的市场反馈；
- 与杜芃烨对齐企业决策的 LLM 执行，与郝依琳对齐 Lange 市场反馈；
- 不直接修改权威世界状态。

## 郝依琳

**角色：Planning 与 Labor Allocation 负责人。**

- 负责 Cockshott 中央计划机制；
- 负责 Lange 中央计划方的试探价格、反馈读取和调整逻辑；
- 负责计划经济中的集中式岗位或劳动分配；
- 与王逸忱对齐 Lange 的市场执行与反馈接口；
- 向 `Engine` 和 World 返回计划、价格信号或劳动分配结果；
- 不直接修改权威世界状态。

## 当前评审约定

- 项目推进、整体架构、接口完整性与集成：张馨月负责；
- LLM、软件架构、计算实验和技术可行性：李文浩提供咨询与评审；
- 经济机制、制度解释和比较公平性：刘充提供咨询与评审；
- 各模块内部结构、提供接口和所需接口：对应模块负责人提出；
- 本轮任务范围和交付要求：[1123任务文档](tasks/T-008.md) 为唯一金标准；
- 需要先经张馨月和刘充双人评审再开放的重大修改，采用 [受控提案双人评审工作流](../project/workflows/gated-proposal-review.md)。
