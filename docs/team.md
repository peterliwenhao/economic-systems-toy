# 团队与职责

本页记录当前协作分工。职责用于明确沟通和评审边界，不意味着研究成员只能处理所列事项；重要方向变化由团队共同确认。

## 李文浩

**角色：项目负责人；LLM 与计算方向研究顾问。**

- 负责项目整体协调、研究内容把控与阶段验收；
- 就 LLM 策略、计算实验、工程架构和评测设计提供建议；
- 承担部分实验与关键技术难点；
- 确保结论与证据相称，并协调跨角色决策。

## 张馨月

**角色：本科生研究成员；项目主要执行负责人。**

- 在团队指导与共同评审下，负责项目的日常推进和核心工作落地；
- 负责整理研究设计、实现主要代码、执行实验并维护清晰的过程记录；
- 主动标记不确定性、阻塞和需要专业确认的问题；
- 在形成重要研究选择或解释前，与李文浩及相应领域顾问讨论确认。

张馨月的“主要代码”指研究环境、机制、策略、实验与分析代码；**不包括网站前端、Dashboard、可视化门户或部署基础设施的搭建与维护**。这些展示与运维工作由项目负责人及技术侧统一处理，不应占用她的研究执行时间。

该角色强调她是项目的核心研究参与者和主要推进者，而不是仅承担机械性任务。任务应提供清楚背景、合理学习空间和可获得的评审支持。

## 刘充

**角色：经济学研究顾问。**

- 对经济机制、行为假设、福利定义与结果解释进行专业把关；
- 在研究设计的关键节点提供意见，识别可能的概念混淆或不公平比较；
- 根据项目需要提供咨询支持，不承担日常执行责任。

刘充不负责网站前端、Dashboard、可视化门户或部署基础设施的搭建与维护；如需查看项目状态，直接使用已部署的协作页面和研究文档即可。

## 当前评审约定

- LLM、软件架构与计算预算问题：优先由李文浩评审；
- 经济机制、目标函数与制度解释问题：优先请刘充评审；
- 日常实现、实验和文档：由张馨月主导推进，阶段成果进入团队评审；
- 涉及核心研究问题、指标或结论的改变：三方均应可见并记录依据。
