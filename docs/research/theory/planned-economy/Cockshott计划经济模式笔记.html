Cockshott 计划经济模式笔记

按“生产—分配—流通—消费”整理；以劳动时间核算、计算计划与反馈控制为核心

一、理论定位：以计算替代市场价格协调

Cockshott 与 Cottrell 的方案是对马恩非商品化分配思想的现代计算化推进。它不以兰格式生产资料会计价格的试错为核心，而以社会必要劳动时间、投入产出计算、计划服务器和消费反馈协调资源配置。

该体系保留消费选择，却不把消费品价格理解为资本主义利润最大化的结果。消费品可有用于出清的市场价格 pi，但其基准是劳动价值 vi；个人收入则主要以劳动券而非可积累货币取得。

二、生产：民主确定目标，算法求解生产计划

1. 宏观劳动预算与长期框架

先由社会决定净劳动时间如何在个人消费、公共消费、投资与储备之间分配：

Lnet = C + G + I + B

其中，C 为个人消费品总劳动量，G 为公共消费，I 为投资，B 为储备。若现有公共资金或公共存量折算为 Z，则需由劳动承担的净公共负担为：

T = (G + I + B) − Z，　t = T / (N × 52)

这里，N 为劳动人口，t 为每人每周应承担的社会劳动时间。随后，长期战略层给出例如能源结构、交通方式、营养结构、环境约束和目标增长率 r 的方向性框架。

2. 投入产出计划

设 A 为投入系数矩阵，y 为最终需求向量，x 为总产出向量，则基本物量平衡为：

x = Ax + y，　因此　x = (I − A)−1y

计算上可采用雅可比迭代：

x(k+1) = Ax(k) + y

它说明：最终需求 y 并非只决定消费品产量，而会沿投入产出网络逐层生成对钢铁、能源、机器、运输等中间产品的需求。

3. 和谐函数：处理稀缺资源下的优先级

当资源不足、不能同时满足全部目标时，计划不再只是精确求解 x = (I − A)−1y，而需在可行方案中优先满足更紧迫的目标。和谐函数 H(x) 用来评价实际产出向量与社会目标之间的总体匹配度；计划算法调整产量与资源分配，直至 H(x) 不再显著提高。

投入产出方程解决“满足目标所需的相互依赖关系”；和谐函数解决“目标彼此冲突、资源不足时先满足什么”。

三、劳动价值核算：生产成本的统一尺度

劳动价值 vi 指生产第 i 种产品所需的直接劳动与全部间接劳动之和。设 l 为单位产品直接劳动向量，μ 为复杂劳动折算系数，则劳动价值向量满足：

v = vA + l·μ
v = l·μ(I − A)−1

迭代形式为：

v(k+1) = v(k)A + l·μ

该核算结果随技术、投入结构和生产率变化而定期更新，是消费品劳动价值标签、宏观劳动预算和计划比较的共同尺度。

四、分配：劳动券、社会扣除与激励

个人劳动券由实际工作时间、贡献调整系数与公共扣除共同决定：

Wi = Lworked,i × αi × (1 − t)

其中，t 为用于公共消费、投资和储备的扣除率；αi 为贡献校正系数。讲稿中以 A/B/C 三档示例：

αA = 1.2，　αB = 1.0，　αC = 0.8

劳动券是个人从消费品基金中领取产品的凭据，不应具有货币的全部功能：不可用作资本积累、不可形成利息收入、不可无限转让和贮藏。它实现的是消费权分配，而不是资本所有权分配。

五、流通：双重标价与消费品出清

1. 双重标价

每种消费品同时有两个数：

  • 劳动价值 vi：由劳动价值核算得出，表示社会生产成本，通常按季度或年度更新；
  • 市场价格 pi：由中央营销机构（CMA）通过试错调整，用于使当期消费品供需出清。

价格/价值比为：

Ri = pi / vi

期初可设：

pi(0) = vi

若商品迅速售罄，CMA 上调 pi；若滞销或库存积压，则下调 pi；当商品恰于计划期售罄或保有常规缓冲库存时，视为达到出清目标。可储存商品的调整步长宜较小，易腐品宜较大。

2. 双重标价的含义

pi 不是自由资本主义市场中的利润最大化价格，而是出清工具；vi 使价格信号与社会劳动成本可比较。若 pi > vi，消费者可识别其相对稀缺和较高价格；若 pi < vi，则表示相对充裕。价格与价值同时公开，能够抑制价格调节的过度波动。

与资本主义利润不同，Ri 不应通过压低工资或强化剥削提高；它反映的是产品是否受消费者欢迎，以及企业是否以更少社会劳动生产同等产品。

六、消费与计划反馈：以平等“投票”修正下一期需求

消费者以劳动券购买消费品。每一劳动券代表相同的消费投票权，因此购买行为既是个人选择，也是对下一期产品结构的反馈。设宏观平均价格/价值比为：

R̄ = 劳动券消费总量 / C

下一期最终需求据此调整：

yi(t+1) = yi(t) × f(Ri)
  • Ri > R̄：该商品受欢迎程度高于平均水平，下一期增产；
  • Ri < R̄：低于平均水平，下一期减产；
  • Ri = R̄：维持原计划。

比较基准是宏观平均 R̄，而非机械的 1。当整体消费支出相对计划偏高或偏低时，R̄ 本身会变化；以 R̄ 为基准可同时保持宏观劳动预算与产品间的结构调整。

对你的 LLM-driven ABM 而言，Cockshott 提供的不是“让 LLM 替代计划服务器”，而是一套可先规则化实现的基准闭环：劳动与物资守恒、投入产出求解、劳动券分配、双重标价及消费反馈。之后才可比较：当企业、家庭或计划机构引入 LLM 的记忆、预测和协商能力时，能否更好地识别需求、处理短缺并提高资源配置效率。

一句话概括：Cockshott 以劳动时间为生产核算尺度，以劳动券保障相对平等的消费权，再把消费品出清过程形成的价格/价值比反馈到下一轮投入产出计划中，构成一个可计算、可迭代的民主计划闭环。
