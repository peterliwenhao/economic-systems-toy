# 研究资料目录

研究资料与可执行配置分开保存：

- `theory/planned-economy/`：计划经济理论模式的梳理材料；
- `calibration/`：数值设定、校准说明和人工审阅材料；
- 可执行 YAML 统一放在仓库根目录的 `configs/`，不放在资料目录；
- 已确认的研究设计进入 `docs/project.md`、`docs/interfaces.md` 或 `docs/decisions/`，不能只存在于附件中。
