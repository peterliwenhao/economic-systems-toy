# 项目说明

## 暂定题目

使用受约束 LLM 策略的市场经济与计划经济 Toy Simulation。

题目和具体机制仍可在研究设计阶段调整；当前不要把暂定表述当作最终论文标题或结论。

## 核心研究问题

在相同初始资源、生产技术、偏好、随机冲击及可明确审计的信息与计算预算下，不同资源配置机制在一个小型模拟环境中的表现有何差异？LLM 策略会在哪些条件下改善、恶化或只是增加配置过程的成本与不稳定性？

## 当前研究对象

- 市场机制：个体根据局部信息报价、购买和生产，环境执行撮合、结算与记账。
- 计划机制：规划者在规定的信息范围内分配投入和产出，可分别使用优化、启发式和 LLM 策略。
- 可选混合机制：仅在前两者定义稳定后，再考虑价格与公共品、配额或再分配相结合的设置。

## 第一版范围

- 2–3 种商品；
- 10–30 个经济代理；
- 离散时间；
- 固定且显式的生产与效用函数；
- 可控的随机冲击；
- 规则、优化和 LLM 策略均通过同一合法行动接口进入环境。

第一版不追求现实宏观经济的完整还原，不使用模拟结果直接论证现实市场经济或计划经济孰优孰劣。

## 公平比较原则

1. 不同机制共享同一套环境动力学、初始条件和冲击样本。
2. 信息优势必须单独标注和消融；不能把全知规划者与局部信息市场直接比较后归因于制度。
3. LLM 的上下文、通信、调用次数、模型版本与推理成本必须记录。
4. 必须包含不使用 LLM 的规则、随机和优化基线。
5. 报告多随机种子的分布、置信区间和失败轨迹，而非只选故事性案例。

## 候选指标

- 总福利与总产出；
- 配置效率和相对理论上界的差距；
- 不平等；
- 短缺、积压与未成交量；
- 价格稳定；
- 冲击恢复速度；
- 通信、计算、延迟和 LLM 调用成本。

具体公式、聚合方式和主次指标由 T-001 草案提出，团队评审后确认。

## 已知风险

- “制度”与“策略实现”混淆；
- 规划者的信息优势造成伪比较；
- 小型环境设定主导结论；
- LLM 模型版本、提示词和随机性造成不可复现；
- 从 toy 环境向现实制度作过度外推。
