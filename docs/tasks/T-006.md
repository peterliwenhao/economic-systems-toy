- 基线：最新 `origin/main`

## 目标

基于 `configs/scenarios/closed-economy-fixed-transport-v1.1.yaml`、`docs/WORLD_CONFIGURATION_LAYERS.md` 和校准说明 DOCX，检查参数语义，并把当前完整快照映射为以下四类配置：

1. 世界规则；
2. 初始化规格；
3. 初始化实现例；
4. 实验 treatment。

本任务不建立 actions YAML，也不加入 transport calibration examples；主体的工作地点、角色和逐人禀赋属于初始化实现例。

## 开始方式

```bash
git fetch origin
git switch main
git pull --ff-only origin main
git switch -c task/T-006-refine-world-config
```

不要继续使用已经合并的 `理论梳理` 分支，不要直接在 `main` 修改。

## 重点检查

- `minimum_consumption * 7` 中 7 的时间含义；
- `grain_iron_input_per_unit` 与 `iron_input_per_grain` 的唯一真源；
- `allocation_rule` 属于世界默认还是实验 treatment；
- 默认值与逐主体实现值是否存在双向手改风险；
- 技能、健康和职业是否应作为独立因素轴；
- 字段单位、生成规则、实现值和 seed 是否足以复现。

## 职责边界

不修改 `dist/`、`deploy/`、Dashboard 或其他前端内容。需要李文浩或刘充判断的地方列出备选方案与问题，不自行替团队作最终决定。
