# 会议与讨论记录

复制 `M-000-template.md` 记录会影响团队的讨论。原始讨论可以简略，页面顶部的“已确认结论”和“待决问题”必须清楚。个人调试过程和 Codex 草稿不需要全部提交。

## 会前准备

会议前一天或至少提前数小时，请每位任务负责人：

1. 在自己的任务分支提交并 push 当前可保留的工作；
2. 更新 Issue/PR：已完成、下一步、阻塞、需要会议决定的问题；
3. 附上可复现证据或明确说明尚未运行哪些检查；
4. 不为了开会而把未完成工作合并到 `main` 或临时 `dev`。

李文浩据此复制会议模板，整理议程。会议查看各 PR/commit 即可；只有达到任务验收条件、通过检查和评审的 PR 才合入 `main`。会后所有新任务都从更新后的 `main` 新建分支，不从旧任务分支继续长出下一项工作。
