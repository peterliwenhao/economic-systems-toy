LLM Economic Systems Toy

四个开发子系统与协作流程

四位开发成员分别负责一个边界清楚的子系统，通过共同确认的接口连接； 环境统一执行物理与会计结算，其他模块只提交行为、交易或计划结果。

四个子系统

每个模块由对应负责人独立实现，连线表示双方需要共同定义的接口。

① 世界环境与运行 Engine

  • 世界初始化与状态管理
  • 时间推进与随机种子
  • 生产、运输、库存、消费、健康
  • 权限校验与确定性结算
  • 日志、快照与结果输出

② Agent 与 LLM 接口

  • Agent Observation 构造
  • LLM 与规则 Policy 接口
  • Prompt 与结构化输出
  • 行为、需求与劳动意愿解析
  • 重试、缓存、费用与调用记录

④ 中央计划与劳动匹配

  • Cockshott 中央计划局
  • Lange 中央计划局
  • 劳动与岗位匹配部门
  • 生产目标、调拨与配给计划
  • 后期接入反馈与计划修订

③ 市场与价格系统

  • 买卖报价与订单管理
  • 撮合、交易和市场出清
  • 一般市场价格形成
  • Lange 市场执行层
  • 超额需求与价格试错反馈

简单合作方式

先确认模块之间如何对话，再各自实现，最后统一集成。

  1. 各自写接口草案

    四位负责人分别说明自己模块的输入、输出、数据格式和关键假设。

  2. 馨月组织对齐

    汇总相邻模块的接口，解决字段、流程和责任边界不一致的问题。

  3. 项目评审

    李文浩审阅技术与实验设计，刘充审阅经济机制与假设。

  4. 分头编写

    接口确认后，各负责人独立完成模块代码、测试和必要说明。

  5. 馨月统一集成

    把四个模块接入同一流程，组织联调并记录需要返回修改的问题。

接口先对齐、再开始实现；模块各自负责、集成统一组织。
