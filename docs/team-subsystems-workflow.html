1123 本周怎样合作

  1. 每位负责人独立完成一张可讨论的类图草案。
  2. 每位负责人用 PPT、HTML、Markdown 或口头配图讲清本模块内部如何构成、如何运作。
  3. 每个准备提供的接口单独写一份首次草案；每个希望获得的接口也单独写一份需求草案。
  4. 张馨月在相同基础上完成 Backbone/Engine 草案，并额外画出系统级时序图。
  5. 首次接口会上，由提供方和调用方逐份核对接口用途、Python 签名、输入、输出和待确认问题。
  6. 接口初步对齐后，再补完整字段、异常、样例和测试，并进入公共骨架实现。

本周不要求：正常/边界/失败样例、单元测试、最终字段定稿或功能代码。

首次接口草案最小格式

项目需要回答的内容
接口名称与用途这次调用解决什么问题。
提供方 / 调用方谁实现，谁会调用。
Python 签名用函数或方法的形式写清参数和返回类型；名称可以在会议中修改。
输入 / 输出每项数据表达什么，不要求本周冻结全部字段。
待确认问题仍需哪位负责人或评审者共同决定。
