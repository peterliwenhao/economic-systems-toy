# 配置

可复现实验参数全部使用版本控制内的配置文件，不依赖手动修改代码。第一阶段使用 JSON，避免在代码骨架期引入额外依赖。

```text
configs/
├── environments/  # 商品、代理人数、初始禀赋、冲击
├── mechanisms/    # 市场/计划/混合机制参数
├── agents/        # 规则、优化器、LLM 策略参数
└── experiments/   # 引用上述配置并定义 seeds、指标与比较矩阵
```

配置只能包含相对路径或环境变量名，不能包含 API key、密码或个人路径。任何正式 run 都必须保留解析后的完整配置。
