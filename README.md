# LLM 市场经济与计划经济 Toy Simulation

> 协作入口：[项目交接](docs/HANDOFF.md) · [团队职责](docs/team.md) · [Git 规范](docs/git-workflow.md) · [当前任务](docs/tasks/README.md) · [研究资料](docs/research/README.md) · [项目启动检查](docs/PROJECT_STARTUP.md)

本项目研究：在同一组资源、生产技术、偏好和冲击下，比较不同资源配置机制的表现。

核心原则：经济制度由显式规则实现，LLM 只作为受约束的决策策略之一；同时保留规则、优化和强化学习基线，避免把“模型会聊天”误当作经济机制。

当前阶段：研究设计。张馨月负责推进 `T-001：形成研究设计草案 v0.1`；李文浩负责项目协调及 LLM/计算方向把控；刘充负责经济学方向的专业咨询与关键节点评审。详细、经团队使用的角色表述见 `docs/team.md`。

## 最小研究问题

- 市场机制：代理人根据局部信息报价、购买、生产，环境负责撮合与清算。
- 计划机制：规划者根据可观测信息分配投入与产出，可用优化器、启发式策略或 LLM 实现。
- 混合机制：价格负责一部分资源配置，规划者负责公共品、配额或再分配。
- 比较维度：总福利、产出、配置效率、不平等、短缺/积压、价格稳定、冲击恢复速度、通信与计算成本。

第一版只做 2–3 种商品、10–30 个代理人、离散时间、固定生产函数与可控随机冲击。

## 建议代码结构

```text
src/
  env/          # 状态、生产、消费、冲击、记账
  mechanisms/   # 市场撮合、中央计划、混合机制
  agents/       # 规则策略、优化策略、LLM 策略
  evaluation/   # 指标、统计检验、可视化
configs/        # 实验参数与随机种子
tests/          # 守恒、预算、清算、确定性测试
experiments/    # 实验入口，不存手改后的结果
docs/           # 设计、调研笔记和实验协议
```

## 本科生算法侧应掌握什么

### 必备基础

1. Python 工程：类型标注、dataclass/Pydantic、pytest、日志、配置管理、Git。
2. 概率统计：随机变量、置信区间、效应量、bootstrap、多重比较、随机种子。
3. 优化：线性规划、整数规划的基本建模；能用 SciPy 或 OR-Tools 写社会规划者基线。
4. 仿真：离散时间状态转移、事件顺序、同步/异步更新、守恒量与不变量。
5. 多智能体基础：部分可观测、策略、奖励、集中训练/分散执行的概念；第一版不必先上深度 MARL。
6. LLM 工程：结构化输出、schema 校验、重试与超时、上下文管理、温度和采样、缓存、token/费用记录。
7. 实验设计：对照组、消融、参数扫描、重复试验、预先定义指标，避免只挑故事性案例。

### 建议框架

- 环境核心：先用纯 Python 自建；接口参考 Gymnasium 的 `reset/step`。
- 优化基线：SciPy `linprog` 或 OR-Tools；规模很小时可穷举校验。
- 数据与配置：Pandas/Polars、Pydantic、Hydra（项目变大后再引入）。
- 可视化：Matplotlib/Seaborn；网络结构需要时再用 NetworkX。
- 多智能体/RL：PettingZoo 接口值得参考；只有明确需要学习策略时再评估 RLlib、MARLlib 等重框架。
- LLM 接入：定义自己的 `Policy` 抽象层，把具体供应商 SDK 隔离在 adapter 中。

不建议一开始使用大型 agent 框架。这个项目最难的是环境有效性、机制可比性和测量，而不是工具调用编排。

## 搭建前必须调研的问题

### 形式化与可比性

- 两种制度是否面对完全相同的初始禀赋、生产技术、偏好、信息和冲击？
- “计划者”能看到什么？若让它全知，会把信息优势误算成制度优势。
- 市场如何形成价格与清算？未成交订单、破产、库存和信贷如何处理？
- 规划者的目标函数是什么？总效用、最低效用、公平性之间如何取舍？
- 代理人是否会撒谎、囤积或策略性申报？机制怎样验证或惩罚？
- LLM 的记忆、通信带宽和推理预算是否在各组一致？

### 有效性与工程

- 状态与流量是否满足商品、货币和预算约束？
- 是否存在不用 LLM 就可算出理论最优的小实例，用来验证实现？
- 顺序效应、提示词、模型版本和随机性会怎样影响结果？
- 如何记录每一步状态、行动、原始响应、解析错误、延迟和成本？
- 如何处理无效 JSON、越界行动、超时和模型拒答，并保证规则不因制度不同而偏置？
- 结果能否跨随机种子、规模、冲击类型和模型复现？

## 基线与实验矩阵

至少实现以下策略：

1. 随机合法策略（管线 sanity check）。
2. 简单规则策略（按边际效用消费、按库存调价等）。
3. 全信息社会规划最优解（效率上界，不当作现实计划经济）。
4. 信息受限的启发式规划者。
5. LLM 市场代理人和 LLM 规划者。

关键消融：是否使用 LLM、信息范围、通信预算、代理人数、冲击强度、偏好异质性、模型/提示词。每个条件运行多个种子，报告分布和置信区间，不只报告均值。

## 推荐材料

### 仿真与多智能体

- Sutton & Barto, *Reinforcement Learning: An Introduction*：先读 MDP、策略与评价章节。
- Shoham & Leyton-Brown, *Multiagent Systems*：博弈、机制和多智能体学习的系统入门。
- David O. Sullivan & George Perry, *Spatial Simulation* 或任一本严谨的 agent-based modeling 教材：重点学习验证、校准和敏感性分析。
- Gymnasium 与 PettingZoo 官方文档：学习环境 API 和多智能体交互约定。

### 优化、机制与计算经济学

- Boyd & Vandenberghe, *Convex Optimization*：凸优化、对偶与资源分配相关章节。
- Nisan et al., *Algorithmic Game Theory*：机制设计、拍卖和计算视角。
- Tesfatsion & Judd (eds.), *Handbook of Computational Economics, Vol. 2: Agent-Based Computational Economics*。
- OR-Tools 或 SciPy Optimize 官方教程：把中央规划问题实现成可验证基线。

### LLM 代理与评测

- ReAct、Generative Agents、CAMEL 等代表论文：理解 LLM agent 的行动—记忆—通信设计，但不要直接照搬结论。
- 阅读所用模型的官方结构化输出、采样参数和版本固定文档。
- 重点补充“LLM evaluation reproducibility / prompt sensitivity / agent benchmark contamination”相关综述与实证研究。

学生必须亲自理解并能口头解释：环境状态转移、每条约束、市场清算/规划优化算法、评价指标与统计方法，以及一次完整实验如何从配置复现。提示词草拟、样板代码、绘图和文献初筛可以交给 AI 助手，但模型有效性判断、假设选择、测试设计、异常分析和结论边界不能外包。

## 8 周可执行路线

- 第 1 周：写形式化说明，定义状态、行动、信息集、约束与指标。
- 第 2 周：实现无 LLM 的环境、账本与不变量测试。
- 第 3 周：实现市场规则、优化规划者和手算小实例校验。
- 第 4 周：实现规则代理与基准实验，完成敏感性分析管线。
- 第 5 周：接入结构化 LLM Policy，加入缓存、重试、成本与全轨迹日志。
- 第 6 周：运行信息公平的主实验和关键消融。
- 第 7 周：统计分析、失败案例分类、跨模型/提示词稳健性检查。
- 第 8 周：复现实验、整理限制，区分“该 toy 模型中的发现”和现实制度结论。

## 第一里程碑验收标准

- 固定种子时无 LLM 基线完全可复现。
- 每一步通过商品守恒、预算与行动合法性测试。
- 小规模规划问题与手算/穷举最优解一致。
- 市场和计划机制共享同一环境动力学，只替换配置机制与信息结构。
- 一条命令可运行实验并生成原始轨迹、汇总表和图。
- 即使 LLM 全部失效，实验仍能用非 LLM 基线运行并给出有意义结果。
