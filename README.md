# LLM 市场经济与计划经济 Toy Simulation

本项目构建一个由 LLM 主体参与的小型封闭经济环境，在统一的世界规律、初始禀赋和信息条件下，比较市场机制、Lange 机制与 Cockshott 机制的运行过程和结果。

## 一、基本介绍

### 1.1 研究目标

项目希望把不同经济协调机制转化为可以运行、检查和重复实验的计算模型。第一版关注一个规模较小的 toy environment，包括有限数量的主体、粮食和铁等商品、生产与消费活动，以及市场或中央计划机制下的资源配置过程。

项目当前重点包括：

- 建立统一的世界环境和确定性规律；
- 定义主体能够看到的信息和能够采取的行动；
- 实现市场、Lange 和 Cockshott 等不同协调机制；
- 接入 LLM 与规则基线，使同一类决策可以使用不同决策方式；
- 完整保存配置、行动、状态、机制结果和模型调用记录；
- 在相同初始条件和信息条件下开展可复现实验。

LLM 主要承担受约束的主体决策。生产、运输、库存、消费、健康、市场出清和计划计算等制度与物理过程，由明确的程序规则负责执行和验证。

### 1.2 目标目录结构

项目接下来按照以下类别整理。目录迁移完成前，现有文件位置保持不变。

```text
economic-systems-toy/
├── README.md
├── AGENTS.md
├── src/                       # 可执行的项目代码
│   └── economic_toy/
│       ├── backbone/          # Engine、运行流程和模块装配
│       ├── decision/          # Decision、LLM、Harness 和 Memory
│       ├── world/             # 世界初始化、状态和确定性规律
│       ├── market/            # 商品市场、劳动力市场和企业决策
│       ├── planning/          # Cockshott、Lange 和集中式劳动分配
│       ├── common/            # 对齐后确认的公共类型
│       └── evaluation/        # 后续指标计算
├── tests/                     # 单元测试、集成测试和极小案例
├── configs/                   # 可复用的运行参数模板
├── experiments/               # 正式实验定义和批量运行方案
├── runs/                      # 每次运行的配置快照和结果，不进入 Git
├── materials/
│   └── common/                # 理论、LLM、工程和校准公共材料
├── reports/
│   └── weekly/                # 每周模块说明、类图、接口和汇报材料
├── docs/                      # 当前有效的架构、接口和协作规范
├── project/                   # 任务、会议、Roadmap 和 Dashboard 数据
├── scripts/                   # 构建、验证和运行辅助脚本
├── deploy/                    # 服务器与展示页面部署
└── dist/                      # 自动生成的网站文件
```

其中：

- `materials/common/` 保存供成员共同阅读的输入材料，这些材料可以包含尚未采用的观点；
- `reports/weekly/` 保存带日期的阶段性汇报和设计草案，内容可以随着讨论继续修改；
- `docs/` 保存经过讨论后当前有效的项目说明；
- `src/` 保存实际运行的 Python 代码；
- `configs/` 保存可以重复使用的世界、机制和决策参数模板；
- `experiments/` 说明一次正式实验选择哪些配置、种子和重复次数；
- `runs/` 保存每个 run 实际使用的完整配置快照、轨迹、日志和结果。

每次 run 不需要在 `configs/` 中新增一份配置文件。程序应把模板、实验设置和临时覆盖参数合并，并在对应的 `runs/<run-id>/` 中自动保存 `resolved-config.yaml`。
